## General info
This repository contains scripts for assigning genes to SNPs.
SNP lists are the output of running GAPIT GWAS pipeline on phenotypes

## Project description
![Chromosome-scale LD trend](repo_images/chrom_scale_LD.png)
Above image shows an output of the genomewide LD trends identified using this pipeline


![LD modelling at the genomic window scale](repo_images/genomic_window_LD_modelling.png)
For a pre-specified genomic window, this pipeline models LD decay and identifies the physical distance in base-pairs at which LD starts to reach background levels
